Binary image classification project for malaria screening, built for the MIT Applied Data Science Program. Trains and compares five CNN architectures — including a base CNN, deeper CNNs with Batch Normalization and LeakyReLU, data augmentation, and VGG16 transfer learning — on microscopy images of red blood cells (parasitized vs. uninfected). Model selection is anchored to parasitized recall as the primary clinical metric. Final model (CNN + data augmentation) achieves 97.77% parasitized recall and 97.92% test accuracy. Includes a full executive summary and deployment recommendations. Implemented in TensorFlow/Keras on Google Colab.
